# Support

- **Questions and ideas:** open a GitHub Discussion, or an issue using the *Feature request* template.
- **Bugs:** use the *Bug report* template and include synthetic text only.
- **Security:** see [SECURITY.md](SECURITY.md) and use a private advisory.
- **Scam victims:** this project is a prototype, not a helpline. If money was lost, call **1930** and report at <https://cybercrime.gov.in>.
