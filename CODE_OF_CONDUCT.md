# Code of Conduct

We follow the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, no harassment or discrimination.

This project deals with fraud against vulnerable people, so additionally: **never post real victims' data, real scammer phone numbers or UPI IDs, or real call recordings** in issues, pull requests or fixtures. Use synthetic data.

Report conduct concerns privately to the maintainer (contact details are on their GitHub profile).
