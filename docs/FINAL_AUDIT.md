## Spec acceptance notes (honest)
- **P1 acceptance** "scam fixtures reach critical by the first payment demand": 100% on the 14 tuned fixtures; **88.5% (23/26) across all 26 scams**. The three late held-out scams (electricity bill in Hinglish, remote-access refund, lottery fee) are listed in `evals/report.md` as known limitations of the rules-only detector; they peaked at 51, 78 and 73.
- Held-out false-positive: found on first run, fixed afterwards (disclosed in the report), so held-out numbers are post-fix.
- Eval size: 43 dialogues (26 scam / 17 legit), all synthetic and authored by the same person who wrote the rules; treat as a regression suite, not a benchmark.
- Latency p50/p95 and tokens per session by tier: **not measured** (need a live key).
- Frontend is Next 16 / React 19, not Next 14 (security; see DECISIONS #19).
- Voice: browser Web Speech only is verified-by-design; NVIDIA ASR/TTS adapters are unverified. Text mode is unaffected.
- Playwright: 4/4 tests pass on Microsoft Edge here; the bundled Chromium would not launch on this Windows machine (CI uses Chromium). Edge also prints a harmless worker-teardown error after the PDF download test.
- Identity is a random client ID (no accounts), which is a documented security gap.
